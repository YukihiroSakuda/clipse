Markdown 記号を使わないプレーンテキストで書いています。
貼り付け後の見出し指定は、ファイル末尾の「note 貼り付けメモ」を参照。

一覧に並んだとき何が起きるツールなのかが読む前に伝わります。

## 記事本文（ここから）

Windows でスクリーンショットを撮るとき、こんな手順を踏んでいないでしょうか。

Snipping Tool で範囲を選ぶ。ペイントを開いて貼り付ける。矢印を描く。個人情報の部分を四角で塗りつぶす。名前を付けて保存する。……ようやくチャットに貼れる。

1回あたりは数十秒ですが、手順書やバグ報告を書いている日は1日に何十回も繰り返します。この「撮ってから貼るまで」を1つのアプリで終わらせたくて、Clipse というツールを作りました。Windows 10 / 11 向けのデスクトップアプリで、タスクトレイに常駐します。無料・MIT ライセンスのオープンソース、アカウント登録もブラウザも不要です。

基本の流れ

使い方はシンプルです。

まず PrintScreen キーを押します。画面が暗くなり、範囲選択モードに入ります。ここでドラッグすれば自由な範囲、クリックすればカーソル下のウィンドウや UI 要素を自動で認識して選択します。ホイールを回すと認識する範囲を1段階ずつ絞り込めるので、「ボタンだけ」「ダイアログだけ」といった選択がドラッグなしで決まります。

範囲を確定すると、そのまま3つのことが同時に起きます。ファイルへの自動保存、クリップボードへの自動コピー、そして画面右下に小さな通知が出ます。

つまり、撮った直後にはもう Ctrl+V で貼れる状態になっています。加工が要らないときは、ここで終わりです。加工したいときだけ通知をクリックすると、注釈エディタが開きます。

ショートカットは2つだけ

この手のツールは、機能が増えるほどショートカットの表が長くなりがちです。Clipse は覚えるキーを意図的に2つに絞りました。

PrintScreen で撮る。Ctrl+PrintScreen でそれ以外の全部に行く。

Ctrl+PrintScreen を押すと、マウスカーソルの位置に小さなメニューが出ます。中身はこの9項目です。

・Open Gallery（撮影履歴を開く）
・Take Screenshot（範囲キャプチャ）
・Repeat Last Region（直前と同じ範囲でもう1枚）
・Capture This Monitor（カーソルのあるモニター全体）
・Capture All Monitors（全モニターを1枚に合成）
・Scrolling Capture（縦長ページのスクロールキャプチャ）
・Fixed-Size Capture（サイズ・比率を指定してキャプチャ）
・Record Screen（画面録画）
・Settings（設定）

矢印キーで選んで Enter。マウスに持ち替えても構いません。ホットキーの表を暗記しなくても、全機能に2アクションで届きます。

なお、この2つのキーは設定から自由に変更できます。PrintScreen を他のツールに取られている環境でも、好きなキーに割り当て直せます。

キャプチャの種類

範囲・ウィンドウ・全画面という基本のほかに、実務で効くものをいくつか。

スクロールキャプチャは、縦に長い Web ページや設定画面を自動でスクロールしながら撮影し、1枚の画像につなぎ合わせます。スクロール量と待機時間は設定で調整できるので、読み込みの遅いページにも合わせられます。

直前と同じ範囲での再キャプチャ（Repeat Last Region）は地味ですが使用頻度が高い機能です。同じダイアログの「操作前」「操作後」を並べたいとき、範囲を選び直さずに済みます。

固定サイズキャプチャは、16:9 や 4:3 といった比率、あるいは 1920×1080 のようなピクセル数を指定して撮る機能です。資料に並べる画像のサイズを揃えたいときに使います。

画面録画は MP4 と GIF に対応しています。操作手順を数秒で見せたいときは GIF、長めの記録には MP4、と使い分けられます。

マルチモニターと DPI 混在の環境（4K ノート + フル HD 外部ディスプレイのような構成）にも対応しています。モニターごとに拡大率が違っても、選択範囲がずれたり画像が引き伸ばされたりしません。

注釈エディタ

エディタのツールはすべてファンクションキーに割り当ててあります。Space が選択、F1 矢印、F2 ペン、F3 直線、F4 四角形、F5 楕円、F6 テキスト、F7 番号マーカー、F8 ハイライト、F9 ぼかし／黒塗り、F10 スポットライト、F11 切り抜き、F12 マグニファイア。

このなかで特に使うものを紹介します。

番号マーカー（F7）は、置くたびに自動で連番になります。手順書の「①ここをクリック → ②ここに入力」を作るのが速いです。一度大きさを変えれば次からも同じサイズで作られます。

ぼかし／黒塗り（F9）は、メールアドレスや社内情報のマスキング用です。ぼかしの強さはスライダーで調整できます。

マグニファイア（F12）は、指定した範囲を拡大して引き出し線で隣に表示する注釈です。「小さなチェックボックスの状態」を示したいときに、全体像と拡大図を1枚に収められます。

矢印（F1）は、四角形や楕円の接続点に吸着する Excel 風のコネクタとして使えます。図形を動かすと矢印も追従します。

色・太さ・不透明度といった設定は、次に描くものへ自動的に引き継がれます。同じ色の矢印を5本引くのに、5回色を選ぶ必要はありません。

Undo / Redo（Ctrl+Z / Ctrl+Y）、ズーム（ホイール）、パン（中ボタンドラッグ）、注釈の複製（Ctrl+D）、1px 単位の移動（矢印キー、Shift で 10px）といった基本操作も一通り揃えてあります。

エディタは複数同時に開けます。注釈を書いている最中に別のスクショを撮っても、編集中の画像が置き換わることはありません。開いているエディタ間で注釈のコピー＆ペースト（Ctrl+C / Ctrl+V）もできます。

ギャラリーとその他の機能

撮影した画像はすべてギャラリーに残ります。ダブルクリックで再編集、名前の変更、削除、保存フォルダを開く操作はここから行えます。★を付けたキャプチャは「Important」フィルタで素早く絞り込めます。

画面へのピン留め（Ctrl+P）は、画像を常に最前面の小さなウィンドウとして切り出す機能です。仕様書のスクショを横に貼り付けたまま作業する、といった使い方ができます。Ctrl+ホイールで拡大縮小、ドラッグで移動します。

OCR（Ctrl+Shift+O）で画像内の文字を抽出できます。これは Claude Code または Codex CLI を使う実装なので、どちらかがインストール済み・サインイン済みである必要があります。実行すると画像がそれぞれの提供元に送信される点はご注意ください。

主な設定項目

・保存先フォルダ（既定はアプリデータ内、任意のフォルダに変更可）
・ファイル名パターン（{date} {time} などのトークンで指定）
・保存形式 PNG / JPEG と JPEG 画質
・キャプチャ後にエディタを開く（既定はオフ、通知から開く運用）
・マウスカーソルを含めて撮影
・システム起動時に自動起動
・グローバルショートカットの再割り当て
・スクロールキャプチャの待機時間
・OCR エンジン（自動 / Claude Code / Codex）
・説明文の言語（日本語 / 英語）

導入方法

GitHub の Releases からインストーラをダウンロードして実行するだけです。管理者権限は不要で、ユーザー単位でインストールされます（MSI 版もあります）。

https://github.com/YukihiroSakuda/clipse

インストールするとタスクトレイにアイコンが常駐します。左クリックでギャラリー、右クリックでメニュー。あとは PrintScreen を押してみてください。

技術的には Tauri v2（React + Rust）で作っています。Electron 製のツールに比べてメモリ消費が小さく、常駐させっぱなしにしても気になりません。

「撮る」から「貼る」までの間にある小さな摩擦を全部削ることだけを考えて作ったツールです。同じところで消耗している方に届けば嬉しいです。

## note 貼り付けメモ

note のエディタは Markdown をそのまま解釈しないため、本文はプレーンテキストで書いてあります。
貼り付けたあと、以下の行を選択して「見出し（大／中）」に指定してください。

大見出し（h2）にする行:

- 基本の流れ
- ショートカットは2つだけ
- キャプチャの種類
- 注釈エディタ
- ギャラリーとその他の機能
- 主な設定項目
- 導入方法

そのほか:

- 「・」で始まる行は、note の箇条書き（リスト）に変換すると読みやすくなります
- GitHub の URL は単独行のままにしておくと note がカード表示にしてくれます
- 見出しごとにスクリーンショットを1枚ずつ挟むと、note では格段に読まれやすくなります
  推奨: 範囲選択中のオーバーレイ / 注釈エディタ全景 / クイックメニュー / ギャラリー
- 冒頭にアイキャッチ画像（アプリアイコン or エディタ画面）を設定してください
- 推奨ハッシュタグ: #個人開発 #Windows #スクリーンショット #Rust #Tauri #オープンソース
