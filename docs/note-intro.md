## A. 標準（約400字）— 記事冒頭のリード、または単独の紹介文

Clipse は、Windows で「スクショを撮る → 加工する → 貼る」を1つで終わらせるための常駐ツールです。

PrintScreen を押して範囲を選ぶと、その瞬間にファイルへの保存とクリップボードへのコピーが両方終わっています。加工が要らなければ、もう Ctrl+V で貼れる状態です。矢印や連番マーカー、ぼかしを入れたいときだけ、右下に出る通知をクリックして注釈エディタを開きます。ペイントを経由する必要はありません。

覚えるキーは2つだけです。PrintScreen で撮る。Ctrl+PrintScreen でそれ以外の全部——スクロールキャプチャ、全モニター合成、画面録画、直前と同じ範囲での再撮影、ギャラリー、設定——にカーソル位置のメニューから届きます。ホットキーの表を暗記する必要はありません。

Tauri v2（React + Rust）製なので常駐させても軽く、アカウント登録もブラウザも不要。無料・MIT ライセンスのオープンソースです。

## B. 短め（約180字）— note の記事概要、プロフィール欄

Windows 用のスクリーンショットツール「Clipse」を作りました。

PrintScreen で範囲を選んだ瞬間に、保存とクリップボードへのコピーが終わります。撮ったらもう Ctrl+V で貼れる。矢印・連番マーカー・ぼかしを入れたいときだけ、通知をクリックして注釈エディタを開きます。

覚えるキーは PrintScreen と Ctrl+PrintScreen の2つだけ。無料・オープンソース（MIT）です。
