Clipse

画面キャプチャ・注釈ツール

Windows 10 / 11 デスクトップアプリ（Tauri 製）・タスクトレイ常駐型

1 / 8
01 — Overview

Clipse とは

  • 画面のキャプチャから注釈・共有までを 1 つで完結させる Windows 用ツールです。
  • PrintScreen キーを押すだけで範囲選択が始まり、撮影後は通知（トースト）が表示されます。クリックすると注釈エディタが開きます。
  • 撮影した画像は自動保存され、ギャラリーからいつでも再編集・コピーできます。
  • タスクトレイに常駐する軽量アプリで、ブラウザやアカウント登録は不要です。

02 — Capture

キャプチャ機能

範囲キャプチャ

PrintScreen で起動。クリックでウィンドウや UI 要素を自動認識、ドラッグで自由選択。マウススクロールで選択範囲の絞り込みも可能。

ウィンドウ / 全画面

アクティブウィンドウ単位、またはモニター単位の全画面キャプチャ。複数モニター・異なる DPI の混在環境に対応。

スクロールキャプチャ

縦に長いページを自動スクロールしながら撮影し、1 枚につなぎ合わせます。スクロール量・待機時間は設定で調整可能。

画面録画（MP4 / GIF）

モニターを選んで画面を録画。手順の共有には GIF、長めの記録には MP4 と使い分けられます。

固定サイズ / 比率キャプチャ

トレイから起動。16:9・4:3 などの比率、または 1920×1080 などの正確なピクセルサイズを指定してキャプチャできます。

前と同じ範囲を再キャプチャ

トレイメニューの「Repeat Last Region」で、範囲選択をやり直さずに直前と同じ位置・サイズを即座に撮り直せます。

03 — Annotate

注釈エディタ

キャプチャ直後に自動で開きます。ツールはすべてファンクションキーで即切り替えできます。

Space選択 F1矢印 F2ペン F3直線 F4四角形 F5楕円 F6テキスト F7番号マーカー F8ハイライト F9ぼかし / 黒塗り F10スポットライト F11切り抜き F12マグニファイア
  • 番号マーカーは自動で連番になり、手順書の作成に便利です。サイズはリサイズやスライダーで変更でき、次回も同じ大きさで作成されます。
  • ぼかし / 黒塗りで個人情報や機密部分をマスキング。ぼかしの強さはスライダーで細かく調整できます。
  • マグニファイア注釈は指定した範囲を拡大し、引き出し線でつないで隣に表示。スポットライトと同様、円形 / 四角形を切り替えられます。
  • 四角形・楕円は回転に対応。矢印は図形の接続点に吸着する Excel 風コネクタとして使えます。
  • 色・太さ・不透明度などの設定は次の描画に自動で引き継がれます。数値はスライダー横の入力欄で直接指定も可能。
  • Undo / Redo、ズーム、パンに対応。編集結果はワンキーで保存・コピーできます。

04 — Manage

ギャラリーと便利機能

  • 撮影履歴を一覧表示。ダブルクリックで再編集、名前変更・削除・保存フォルダを開く操作もここから行えます。
  • お気に入り。★マークを付けたキャプチャは「Important」フィルタで一覧から素早く絞り込めます。
  • 画面にピン留め。エディタ・ギャラリーどちらからも、常に最前面に表示される小さなウィンドウとして切り出せます。Ctrl+ホイールで拡大縮小、ドラッグで移動。
  • OCR（文字認識）で画像内のテキストを抽出してコピーできます。OCR には Codex CLI を利用します（codex コマンドのインストールが必要）
  • クリップボード連携。「キャプチャ後に自動コピー」を有効にすると、撮影してそのままチャットや資料に貼り付けられます。
  • ファイルは PNG / JPEG で保存。ファイル名は clipse_日付_時刻 形式（パターン変更可）。

05 — Settings

主な設定項目

  • 保存先フォルダ既定はアプリデータ内。任意のフォルダに変更可
  • ファイル名パターン{date} {time} などのトークンで自由に指定
  • 保存形式（PNG / JPEG）と JPEG 画質
  • キャプチャ後にクリップボードへ自動コピー
  • カーソルを含めて撮影 / システム起動時に自動起動
  • 説明文の言語（日本語 / 英語）

06 — Shortcuts

覚えておきたいショートカット

PrintScreen範囲キャプチャを開始（どの画面からでも）
Ctrl + PrintScreenカーソル下のモニターを即時キャプチャ（右クリックメニューも写せる）
Space / F1 〜 F11エディタの注釈ツールを切り替え
Ctrl + C選択した注釈、または画像全体をコピー
Ctrl + Sギャラリーへ保存
Ctrl + Z / Y元に戻す / やり直し
Ctrl + A注釈を全選択
Delete選択した注釈を削除
Esc選択解除・キャンセル

全ショートカットの一覧はアプリ内のヘルプ（? ボタン）から確認できます。

07 — Getting Started

導入方法

  1. 配布されたインストーラを実行します。管理者権限は不要です。数クリックで完了します
  2. インストール後、タスクトレイに Clipse のアイコンが表示されます。「システム起動時に起動」を有効にすると次回から自動で常駐します
  3. PrintScreen を押して、最初のキャプチャを撮ってみてください。
